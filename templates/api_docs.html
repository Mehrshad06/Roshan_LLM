راهنمای API سندیار

یک سند را بارگذاری کنید، بخش مرتبط را پیدا کنید و پاسخ مستند بگیرید.

اولین درخواست

در مرورگر با حساب خود وارد شوید. در PowerShell دستور زیر رمز حساب دمو را می‌پرسد و فهرست اسناد آن را برمی‌گرداند.

curl.exe -u demo http://127.0.0.1:8000/api/documents/

در درخواست‌های نوشتنی با نشست مرورگر، مقدار کوکی csrftoken را در هدر X-CSRFToken بفرستید.

اسناد و جست‌وجو

GET /api/documents/
فهرست شخصی. پارامتر اختیاری search عنوان، نام فایل و متن را جست‌وجو می‌کند.
GET /api/documents/search/?q=ALF-27
تا چهار قطعهٔ مرتبط با عبارت، به ترتیب رتبه. جست‌وجوی ترکیبی روی دستگاه اجرا می‌شود.
POST /api/documents/
بارگذاری با multipart/form-data و فیلدهای file و title (اختیاری). پاسخ موفق ۲۰۱ است.
GET · PATCH · DELETE /api/documents/{id}/
خواندن متن کامل، ویرایش title یا text، یا حذف سند. حذف موفق وضعیت ۲۰۴ دارد.

گفت‌وگو و شاهد پاسخ

GET · POST /api/conversations/
گفت‌وگوهای خود را ببینید یا با بدنهٔ خالی یک گفت‌وگو بسازید. مقدار id پاسخ را برای سؤال‌های پیگیری نگه دارید.
POST /api/conversations/{id}/ask/
سؤال را در فیلد question بفرستید. پاسخ ۲۰۱ شامل answer و sources با عنوان سند، محل و نقل‌قول است.
GET · DELETE /api/conversations/{id}/
تاریخچه و شواهد همان نشست را بخوانید یا گفت‌وگو را حذف کنید.
نمونهٔ ساخت گفت‌وگو و پرسیدن سؤال در PowerShell 
$chat = (curl.exe -s -u demo -X POST http://127.0.0.1:8000/api/conversations/) | ConvertFrom-Json
curl.exe -u demo --data-urlencode "question=Which formats does ALF-27 accept?" "http://127.0.0.1:8000/api/conversations/$($chat.id)/ask/"

خواندن خطاها

۴۰۰ ورودی را بررسی کنید. ۴۰۱ یا ۴۰۳ اطلاعات ورود و CSRF را بررسی کنید. ۴۰۴ سند یا نشست در حساب شما پیدا نشد. ۴۰۹ داده هم‌زمان تغییر کرده است؛ دوباره آن را بخوانید. ۵۰۳ متن detail علت مشکل مدل یا سرویس را توضیح می‌دهد.

اگر شواهد کافی نباشد، درخواست پرسش موفق است و فهرست sources خالی برمی‌گردد.

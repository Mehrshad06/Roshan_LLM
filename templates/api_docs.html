مستندات API

در مرورگر از نشست Django و هدر X-CSRFToken برای نوشتن استفاده کنید. برای آزمایش محلی با خط فرمان، نام کاربری و رمز را با HTTP Basic بفرستید. همهٔ مسیرها مخصوص کاربر واردشده‌اند.

متد و مسیرکاربرد
GET /api/documents/?search=...فهرست و جست‌وجو در عنوان، نام فایل و متن
POST /api/documents/بارگذاری multipart با file و عنوان اختیاری title
GET /api/documents/{id}/جزئیات و متن کامل
PATCH /api/documents/{id}/ویرایش title یا text و به‌روز کردن نمایه
DELETE /api/documents/{id}/حذف سند و قطعه‌های آن
GET, POST /api/conversations/فهرست یا ساخت یک گفت‌وگو با بدنهٔ {}
GET, DELETE /api/conversations/{id}/تاریخچه و شواهد یا حذف گفتگو
POST /api/conversations/{id}/ask/ثبت پرسش با فیلد question

مثال PowerShell

curl.exe -u demo http://localhost:8000/api/documents/

پاسخ پرسش شامل answer و فهرست sources است. هر شاهد شناسه و عنوان سند، محل و نقل‌قول دارد. جزئیات درخواست‌ها، نمونهٔ JSON و کدهای خطا در فایل docs/API.md بسته آمده است.
